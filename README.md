# Think-O-Meter 🧠

A lightweight Python CLI diagnostic tool built to measure how many unnecessary tabs are running in your brain at 2 AM.

## Features
- **3-Question Mental Checkup:** Quick, relatable prompts to gauge daily overthinking levels.
- **Instant Brain CPU Diagnosis:** Calculates your current overthinking percentage and gives a practical prescription.
- **Zero Dependencies:** Built purely with Python's standard library (`os`, `random`, `sys`, `time`).
