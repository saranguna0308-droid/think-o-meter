## How to Run

1. Clone the repository:
   ```bash
   git clone [https://github.com/saranguna0308-droid/think-o-meter.git](https://github.com/saranguna0308-droid/think-o-meter.git)
   cd think-o-meter
   ```
2. Run the script:
   ```bash
   python overthink_o_meter.py
   ```

> *P.S. There's a quiet Easter egg tucked inside for those who know what to type.*
